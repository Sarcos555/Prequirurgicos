# Prequirúrgicos · Intérprete de laboratorio prequirúrgico

App web (PWA) que funciona sin conexión. Parámetros y valores de referencia:
hemograma completo (hematocrito, hemoglobina, hematíes, glóbulos blancos, fórmula con neutrófilos segmentados, eosinófilos, basófilos, linfocitos y monocitos, MCV, HCM, CHCM, RDW, plaquetas), tiempo de protrombina, RIN, APTT, glucemia, uremia, creatinina, ionograma (sodio, potasio, cloro), hepatograma (bilirrubina total y directa, fosfatasa alcalina, TGO, TGP), colesterol total, TSH, β-hCG (negativo < 5; dudoso 5–25; positivo > 25 mUI/mL) y HIV (negativo < 1,0).

> Herramienta educativa y orientativa. No emite autorización quirúrgica ni sustituye el juicio clínico. Usar solo datos anonimizados. No guarda ni envía resultados de pacientes.

## Ajustes
La pestaña **Ajustes** permite ocultar parámetros y editar los rangos y los valores críticos (por sexo). Se guardan en el dispositivo. Los valores críticos son valores generales de referencia y deben adaptarse al laboratorio local.

## Publicar
Sube `index.html`, `manifest.webmanifest`, `sw.js` y este README a la raíz de un repositorio público y activa GitHub Pages (Settings → Pages → `main` / root). En el iPhone: Safari → Compartir → Añadir a pantalla de inicio.
